# Аналізатор розкладу занять (Лабораторна робота №1)

## Призначення
Програма читає записи про навчальні заняття з файлу `data/input.csv`, перевіряє їх на коректність, обчислює статистичні показники (найменший номер аудиторії, найдовше заняття, сумарна тривалість тощо) та формує звіт у консоль і текстовий файл.

## Формат входу
Один запис розміщують у рядку, поля розділяють крапкою з комою (`;`). Файл кодується у UTF-8. 
Формат рядка: `subject: String; teacher: String; day: String; room: int; durationMin: int`

Приклад коректного рядка:
`КЗП; Олексів М.В.; Понеділок; 114; 90`
