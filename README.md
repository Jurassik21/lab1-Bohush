# Аналізатор розкладу занять (Лабораторна робота №4)

## Опис проєкту
Цей проєкт — це консольна Java-програма для читання, валідації та обробки записів розкладу занять. У четвертій лабораторній роботі циклову обробку даних було замінено на декларативні запити за допомогою Java Stream API, що дозволило відокремити логіку фільтрації, перетворення та агрегації від механізмів виводу.

**Варіант 3:** Заняття (предмет, викладач, день, аудиторія, тривалість).

## Нові можливості (Stream API)
Програма реалізує п'ять спеціалізованих потокових запитів та безпечний пошук:
1. **Відбір (filter):** Залишає лише заняття, заплановані на визначений день (наприклад, "Понеділок").
2. **Перетворення (map):** Формує алфавітний список унікальних назв предметів, використовуючи `distinct()` та `sorted()`.
3. **Групування (groupingBy):** Підраховує кількість проведених занять для кожного викладача окремо.
4. **Статистика (summarizingInt):** Автоматично розраховує кількість, мінімальну, максимальну та середню тривалість занять.
5. **Складене впорядкування (top-N):** Знаходить 5 найдовших занять, сортуючи їх за спаданням тривалості, а при однаковий тривалості — за алфавітом назви предмета.
6. **Безпечний пошук (Optional):** Знаходить перше заняття у вказаній аудиторії без ризику отримання `NullPointerException`.
