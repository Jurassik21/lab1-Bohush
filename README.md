# Лабораторна робота №3: Спадкування, інтерфейси й поліморфізм у Java-проєкті

**Предметна область:** Розклад занять (Варіант 3)

## Опис поліморфної моделі
У цій версії проєкту класову модель розширено з використанням принципів спадкування та поліморфізму. Обробка розкладу тепер базується на абстрактному класі та його спеціалізованих підтипах.

* **Базовий тип (`Lesson`):** Абстрактний клас, що містить спільні поля (предмет, викладач, день, аудиторія, тривалість) та інваріанти валідації. Реалізує узгоджені методи `equals` та `hashCode` для порівняння занять, а також оголошує абстрактний поліморфний метод `calculateResourceNeeds()`.
* **Підтипи (`Lecture` та `Practice`):** Наслідують базовий клас і надають власну реалізацію розрахунку потреби в ресурсах (Лекції: тривалість * 1.5, Практики: тривалість * 3.0).
* **Enum (`LessonKind`):** Перелічуваний тип для фіксації категорії заняття, який використовується при формуванні об'єктів.
* **Поліморфізм:** Головний цикл програми викликає `calculateResourceNeeds()` через спільний тип `Lesson`, а Java автоматично визначає, яку формулу застосувати, без використання розгалужень `if` чи `switch`.
