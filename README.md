# Лабораторна робота №1-2: Класи, record і інкапсуляція в Java-проєкті

**Предметна область:** Розклад занять (Варіант 3)

## Опис перебудови (Рефакторинг)
У цій версії проєкту предметну частину було повністю перебудовано згідно з принципами ООП. 
* **До рефакторингу:** Дані читалися як звичайні рядки (`String`), розбивалися масивами (`split`) і перевірялися безпосередньо у циклі `Main.java`. Підсумкові показники зберігалися у розрізнених змінних.
* **Після рефакторингу:** Створено повноцінний клас-сутність `Lesson`, який інкапсулює дані та перевіряє їх при створенні. Для зберігання фінальних показників використовується незмінний `record RoomDuration`. Зовнішня поведінка програми та звіт залишилися незмінними.

## Структура даних та Валідація
* **Клас `Lesson`**: Має незмінні поля (private final) `subject`, `teacher`, `day`, `room`, `durationMinutes`. 
  * **Інваріанти (Валідація):** Конструктор не пропускає `null`, порожні текстові поля, а також вимагає, щоб номер аудиторії та тривалість заняття були строго додатними числами (> 0).
  * **fromCsv:** Статичний фабричний метод, який розбирає CSV-рядок та перевіряє наявність рівно 5 полів і правильність числових форматів.
* **Record `RoomDuration`**: Допоміжний тип для збереження загальної статистики (кількість коректних записів, найменша аудиторія, найдовше заняття, сумарний час). Відхиляє від'ємні значення.
