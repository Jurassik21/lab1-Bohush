# Лабораторна робота №1: Обробка CSV-файлів (Java)

**Проєкт**: lab1-Bohush

## Призначення програми
Консольний застосунок на Java для читання, валідації та аналізу записів розкладу занять із CSV-файлу. Програма ігнорує пошкоджені рядки, збирає статистику (кількість коректних записів, найменший номер аудиторії, найдовше заняття, сумарна тривалість) і формує текстовий звіт.

## Формат входу
Програма очікує CSV-файл із роздільником `;`. Кожен рядок має містити 5 полів, з яких останні два — обов'язково невід'ємні числа.

## Команди запуску
Програма підтримує аргументи командного рядка:
* **Звичайний запуск**: `java -jar target/lab01-bohush-1.0.0.jar --input data/input.csv --output out/report.txt`
* **Довідка**: `java -jar target/lab01-bohush-1.0.0.jar --help`
* **Версія**: `java -jar target/lab01-bohush-1.0.0.jar --version`
